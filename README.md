# Biolink do Centro de Convenções de Teresina (CCT)

Biolink de página única, feito pela VOLTZ MEDIA. Uma só `index.html` serve as duas versões:

- **Mobile** (até 1023 px): rolagem contínua, abertura jogável, menu de vidro flutuante e mascote pelas bordas.
- **Desktop** (a partir de 1024 px): abertura com foto da fachada, barra de rolagem guiada e layouts em colunas.

`index.html` é autossuficiente (imagens embutidas). Basta abrir o arquivo ou hospedar em qualquer lugar estático.

Pastas: `src/` (template e script de montagem) e `img/` (imagens otimizadas usadas pela página).
